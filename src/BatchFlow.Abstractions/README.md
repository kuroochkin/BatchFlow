# BatchFlow.Abstractions

Минимальный слой контрактов для `BatchFlow`.

Содержит только:

- контракты источников данных;
- контракты контрольных точек;
- контракты обработки;
- контракты обработки ошибок;
- контракты наблюдаемости;
- контексты выполнения;
- модели результатов.

Поддерживает два сценария источников данных:

- источники с поддержкой возобновления через `IBatchSource<TItem, TCheckpoint>`;
- источники без поддержки возобновления через `IBatchSource<TItem>` и тип `NoCheckpoint`.

Проект не должен зависеть от:

- `ILogger`;
- `IServiceCollection`;
- OpenTelemetry;
- конкретных баз данных, брокеров сообщений, файловых API или HTTP-клиентов.
